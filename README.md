# SNBLA Frontend

This is the frontend of the SNBLA application, built using React, Redux, Apollo Client, TypeScript, Tailwind CSS, and i18next for internationalization. This project is structured for easy scalability and follows best practices for modern web applications.

## Technologies Used

- **React**: JavaScript library for building user interfaces.
- **Redux**: State management library.
- **Apollo Client**: A powerful GraphQL client.
- **TypeScript**: Typed superset of JavaScript for better code quality.
- **Tailwind CSS**: Utility-first CSS framework for rapid UI development.
- **i18next**: Internationalization framework for handling multi-language support.
- **React Router**: Declarative routing for React.
